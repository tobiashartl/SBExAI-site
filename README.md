# Responsible use of AI: Agentic AI for PhD students

Course website for a hands-on PhD course at the School of Business and Economics,
Maastricht University.

**Website:** <https://tobiashartl.github.io/SBExAI-site/>

**Instructors:** Tobias Hartl and Ines Wilms

**Date:** Tuesday 15 December 2026, 13:00–17:00

## What the course is about

Using AI coding agents in research, with Claude Code as the demonstration tool. The
same workflow works with other agentic AI tools, such as OpenAI Codex. Students work on
one project: they reproduce Table 3 of Card and Krueger (1994), write a short literature
review with verified citations, and present both in a few slides.

## What is on the website

| Page | Content |
|------|---------|
| Course | schedule, learning goals, project, data and AI rules |
| Setup | required installation before the course, step by step with screenshots |
| Slides | the slide decks for each block, including the lab instructions |
| Project | the paper, the deliverables, the take-home, downloads (`ck-project.zip`, `verify-lab.zip`) |
| Resources | documentation and further reading |

## About this repository

This repository contains only the built website (HTML). It is generated from the
course's source files and replaced on every update, so do not edit files here; changes
made here are overwritten.

The paper and data of Card and Krueger (1994) are not included; students download them
from David Card's website. Screenshots of third-party websites and documentation are
credited on the Setup page.
